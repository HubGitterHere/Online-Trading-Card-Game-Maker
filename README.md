A repository for the code of the Online Trading Card Game Maker Project for Senior Software Engineering Project 2026 Fall.
Data within includes pages for designing cards, designing games, playing games, and looking at cards.
Alongside the script for giving those pages functionality.
## How to Install
Project files are made within the Godot Engine. Godot Engine is recommended for editing and testing the codes and files. Link here: https://godotengine.org/
